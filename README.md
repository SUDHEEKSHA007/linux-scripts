#Linux Automation Scripts

This repository contains three Bash scripts/

1. health_check.sh - Checks disk, CPU and memory usage.
2. log_rotator.sh - Rotates log files and removes old backups.
3. service_restarter.sh - Checks and restarts Linux services.

## How to Run

./health_check.sh
./log_rotator.sh app.log
./service_restarter.sh ssh
